# method/

The operating model, written one section per session (D11). Markdown, so it is
version-controlled, diffable and readable on GitHub; any Word or PDF pack is an
export at the end (D18).

| File | Section | Written in |
|------|---------|------------|
| [`decisions.md`](decisions.md) | Every decision, one line each — the single source of *what* was decided | F1, then every session |
| [`01-frame.md`](01-frame.md) | The decision the system supports, the four sub-decisions, roles, lifecycle, value | F1 |
| `02-requirements.md` | Requirements in three classes, each with how it is checked | F2 |
| `03-dataset.md` | The simulated world: weeks, dispute tickets, issues — and why answers are kept apart | F2 |
| `04-harness.md` | Generator, runner, scorecard, holdout | F3 |
| `00-overview.md` | How to read this, and the shape of the process | W |
| `05-release-monitor.md` | Replay, release staging, drift | W |
| `annex-v1-postmortem.md` | What v1 got wrong, and which decision prevents each defect | W |
